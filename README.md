The Poll Automation System is an interactive module designed to streamline the creation, distribution, and analysis of polls within an educational environment. This system empowers educators to engage students dynamically through live polls, feedback sessions, and quick assessments—all in real time.

## Development Setup

This repository uses `pnpm` as the package manager.

1. Enable Corepack (once per machine): `corepack enable`
2. Install dependencies from the repo root: `pnpm install`

Do not run `npm install` in this repository because it can generate a `package-lock.json` that conflicts with the committed `pnpm-lock.yaml`.
